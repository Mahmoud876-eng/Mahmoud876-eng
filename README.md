## What I build

### 🎓 Titan Academy, a production multi-agent education platform
Started as my final-year engineering project, outgrew that label fast.


- Built **2 AI agents with LangChain**, a chatbot agent and a coding agent, each with 10+ custom tools. Key ones include user preference detection, user satisfaction tracking, smart navigation, and dynamic UI rendering.
- Designed a **dual-memory system on Redis**: short-term for conversation context, long-term for personalized user experiences.
- Developed a **RAG pipeline with Redis Vector Store** to give agents accurate, grounded responses.
- Set up **LangSmith** to trace every agent, LLM call, and tool in real time.
- Built a **RESTful API with FastAPI** to expose agent capabilities.
- Deployed models on **Azure AI Foundry** and managed cloud AI infrastructure.
- Used **Pydantic** for structured LLM outputs across all agents.
- Built a **voice avatar with LangGraph**, using graphs, subgraphs, conditional edges, and fan-out patterns to bring course content to life as audio.
